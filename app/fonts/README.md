# Fonts

The site's two typefaces, as Google Fonts serves their Latin subsets, kept in
the repository so that building the site fetches nothing (`app/layout.tsx`
loads them with `next/font/local`).

- `kanit-100-latin.woff2`, `kanit-400-latin.woff2`: Kanit by Cadson Demak,
  SIL Open Font License 1.1 (the licence text is in
  `public/background/fonts/OFL.txt`).
- `roboto-latin.woff2`: Roboto by Google, a variable font covering weights 100
  to 900, Apache License 2.0.
